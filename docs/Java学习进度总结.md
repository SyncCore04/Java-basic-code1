### 2.2 方法（method 包，8 个文件）

**已掌握：**
- 方法定义与调用、参数传递、返回值
- **方法重载（Overload）**：理解参数列表不同才算重载，与返回值无关
- 方法的内存模型（栈内存执行流程）
- 方法封装思想：将复杂逻辑拆分为独立方法

**亮点：**
- `MethodPractice03.java`（快递运费计算）是高质量练习：
  - 用 `while(true)` 做输入校验，直到合法才退出
  - `calculateFee()` 单独封装计费逻辑，职责清晰
  - 用 `final` 常量定义价格，魔法数字消除
  - `Math.ceil()` 处理不足 1kg 向上取整
  - 方法注释规范（@param / @return）

**踩坑记录（笔记中有总结）：**
- 增强 for 循环中的 `i` 是元素不是索引，不能用来 `arr[i]` 访问
- 整数除法丢失精度，计算百分比必须用 `/ 2.0` 或 `/ 1000.0`

### 2.4 算法（algorithm 包，6 个文件）

这是你整个仓库中**最有含金量**的部分，说明你不满足于语法，有主动提升算法能力的意识。

| 题目 | 解法 | 涉及算法思想 |
|------|------|-------------|
| RemoveElement | 快慢指针 | 原地修改数组、双指针 |
| FindMedian | 双指针归并 | 有序数组合并、中位数判定 |
| VoteCount | 计数数组 | 下标映射统计频次 |
| LuckyMoney | 随机分配 | 金额转分避免浮点误差 |
| TrapRainWater | 预处理左右最大值数组 | 木桶效应、空间换时间 |
| TrapRainWaterTwoPointer | 双指针优化 | O(1) 空间优化版 |

**亮点：**
- **接雨水写了两种解法**：先写了 O(n) 空间的预处理数组版，又独立写出 O(1) 空间的双指针优化版，说明你有"写完再想能不能更好"的优化意识
- 快慢指针总结了**通用模板**（slow 记录有效位置，fast 遍历筛选），可复用到"删除有序数组重复项"等题
- 笔记中对每道题都记录了**易错点**（如：查找最高票不能把弃权票纳入对比、偶数中位数要用 `/ 2.0`）

**当前算法水平：** 简单题可独立完成，中等题（接雨水）能理解并实现优化解法。建议继续保持每周 2-3 题的节奏。

## 三、学习习惯评价

### 做得好的地方

1. **有系统的笔记文档**：`docs/我的JAVA笔记.md` 不是抄课件，而是自己的踩坑总结 + 解题模板，这是高效学习的标志
2. **代码注释充分**：算法题都有题目描述、思路说明、关键行注释
3. **工程化意识早**：一开始就用 Maven 管理项目，而不是散文件，目录结构规范（`src/main/java` 分包）
4. **主动拓展**：不仅跟着课程走，还在用 Python 交叉刷算法，说明有自主学习能力
5. **有版本管理**：`.gitignore` 配置正确，说明在用 Git

### 可以改进的地方

1. **缺少单元测试**：`src/test/java` 目录是空的，算法题可以用 JUnit 写断言验证，而不是只靠 `main` 方法打印
2. **OOP 练习偏模板化**：7 组练习都是 Dog/Student/Teacher 的简单重复，可以尝试更有业务含义的类设计（如图书管理、银行账户）
3. **没有完整小项目**：学完封装后应该做一个综合小项目（如学生管理系统控制台版）来串联所有知识点
